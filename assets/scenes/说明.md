# 自制美术素材规格

界面没有这些图也完整可玩（自动隐藏/退回程序化占位），做好放进来即可生效，零改代码。

## 1. 路段场景照片（最出效果，建议优先做）

游戏主界面顶部的"场景带"，显示当前路段的照片，贴在日志里的宽幅照片样式。

- 位置与命名：`assets/scenes/{路段id}.jpg`（小写，见下表）
- 尺寸：**1600 × 900**（16:9），JPG，单张 ≤ 300KB（手机流量考虑，质量 70-80 即可）
- 构图：横幅裁切安全区在**画面中部**——显示时会被裁成约 16:5 的宽条（桌面高 150px / 手机 110px），上下各约 1/4 会被裁掉，主体放中间
- 风格：写实摄影感，与人物立绘一致；偏冷的山地色调最好，界面会给它套白色相纸边框

## 2. 纸纹理（可选）

整个界面的底纹。没有它就用 CSS 画的等高线暗纹，也挺好看。

- 位置与命名：`assets/bg/paper.jpg`
- 尺寸：**512 × 512**，必须**四方连续**（无缝平铺），JPG ≤ 100KB
- 内容：米黄牛皮纸/宣纸纹理，纹理要淡（文字要压在上面），基准色接近 `#e7dcc3`

## 3. 人物立绘（现有的已可用，想换更好）

- 位置与命名：`assets/portraits/{npcId}.png`（12 位角色已齐）
- 尺寸：**512 × 768**（2:3 竖构图），头部在上 1/3，显示时按顶部裁切
- 可选进阶：`{npcId}_{状态}.png` 状态差分图（如 `wangdapeng_膝盖旧伤复发.png`），有就优先显示
