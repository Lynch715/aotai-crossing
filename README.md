# 穿越鳌太线

一个跑在浏览器里的中文文字游戏。**接你自己的大模型 API**，双击一个 HTML 文件就能玩。

鳌太线是秦岭里一条真实存在、且真的会死人的穿越路线。游戏里的 24 个路段、12 个配角、装备清单与四季风险，全部取自下面这份原始素材，一字未改。

## 它和「把提示词丢给对话模型」有什么不同

原素材是一份给对话模型用的文字游戏指令集。直接粘给模型玩，会遇到四个问题：数值会飘、没有画面、操作麻烦、剧情脱轨。

这个项目把**判定挪到了调用模型之前**：

- 前端持有全部数值，模型永远碰不到 `state`，只能**提议**（好感、离队、入队、伤病、去向……），提议一律先过校验才准落地
- 选项**明码标价**——达标显 ✓，勉强写出真实概率，差太远置灰并写明「差 22 点经验」；申报的体力/金钱/时段代价由前端真实结算
- 任何一步失败，整回合原子回滚，绝不留半应用的脏状态
- 商店、捏人、抽卡、进食、休整、求救是原生界面与操作，不经过模型

## 玩

在线：见本仓库的 GitHub Pages 链接。或下载 `dist/穿越鳌太线.html` 双击打开。

需要一个 OpenAI 兼容的 API key（DeepSeek / 硅基流动 / Kimi / 智谱 / OpenRouter 都行）。**key 只存在你自己浏览器的 localStorage 里，不经过任何第三方服务器。**

## 开发

```bash
npm test          # 476 个测试，零依赖
npm run build     # 产出 dist/ 单文件 + assets
AOTAI_KEY=xxx npm run smoke   # 对真实 API 跑一个完整回合
```

设计文档与实施计划在 `docs/superpowers/`。
